# Glassvidia × AgriSence Corp. (Offline UI Prototype)

Open `index.html` in a modern browser. No server, API, CDN, or external font is required.

## Flow
- The Glassvidia liquid-glass sign-in screen is shown first.
- Submitting the form enters the AgriSence Corp. Plant Disease Finder dashboard (demo sign-in only; no authentication backend).
- Upload or drag a leaf photo, choose crop/stage, and run the report preview.
- The report is intentionally a **mock UI preview**. It does not run an AI model, inspect the image, or diagnose crop disease.
- Use the ↗ control in the dashboard header to return to sign-in.

## Included
- Original liquid WebGL background and login glass effect retained.
- Responsive AgriSence Corp. dashboard with matching glass surfaces.
- Local image preview via browser object URL (not uploaded to a server).
- Dark/light theme support and mobile layout.
